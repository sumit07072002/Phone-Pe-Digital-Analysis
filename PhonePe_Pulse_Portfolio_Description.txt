PHONEPE PULSE - PORTFOLIO PROJECT DESCRIPTION

Project overview
This project analyzes PhonePe Pulse data to understand the growth and geographic distribution of digital payment activity in India between Q1 2018 and Q2 2021. The analysis uses quarterly records to explore transaction volume, transaction value, transaction categories, registered users, app opens, mobile-device brands, district-level activity, and district demographics. The objective is to turn multiple raw tables into a coherent view of how activity changed over time and how it varied across states and districts.

Business questions
The analysis was organized around practical questions: How did transaction count and value evolve quarter by quarter? Which states recorded the highest and lowest cumulative transaction counts during the period? How did the mix of payment categories vary by geography? Which device brands had the largest recorded user counts? Did state-level totals reconcile with sums from district records? And was district population associated with transaction volume? These questions help distinguish overall growth from geographic concentration and data-quality issues.

Data and tools
The notebook loads six sheets from the PhonePe Pulse raw-data workbook: state transactions and users, state transaction split, state device data, district transactions and users, district demographics, and administrative mapping information. The saved outputs show 504 state-quarter records, 2,514 transaction-category records, 5,544 device-brand records, 10,248 district-quarter records, and 742 demographic records. Python, pandas, NumPy, Matplotlib, and Seaborn are used for data inspection, grouping, merging, pivoting, correlation analysis, and visual exploration.

Analysis workflow
The workflow starts with data loading and structural review using head(), info(), describe(), and null counts. It then summarizes transaction activity by state, ranks states by total transaction counts, examines category and device-brand data, identifies the most populous district per state, and calculates a state-level average of the Average Transaction Value field as an exploratory metric. The notebook also groups district records by state, year, and quarter and compares the resulting totals with the state-level table. A unique district-name/code mapping is created and exported. Finally, quarterly trends are visualized for the overall dataset and for Uttar Pradesh, and a population-versus-transactions correlation is calculated.

Key trend findings
The quarterly table recorded in the notebook shows strong long-run growth. Summed transaction counts rise from about 134.4 million in Q1 2018 to about 3.94 billion in Q2 2021, approximately 29.3 times the starting level. The corresponding amount rises from about INR 0.172 lakh crore to INR 7.48 lakh crore, about 43.5 times the initial value. Growth was not perfectly monotonic: transaction count fell by about 10.7% and transaction amount by about 1.9% from Q1 to Q2 2020, before both measures increased in subsequent quarters. These observations describe the series; the notebook alone does not establish why the change occurred.

Geographic findings
Across the state-level transaction-and-user table, Karnataka has the highest cumulative transaction count in the covered period, followed by Maharashtra, Telangana, Andhra Pradesh, and Rajasthan. Lakshadweep has the lowest cumulative count, followed by Andaman and Nicobar Islands, Ladakh, Mizoram, and Meghalaya. These rankings describe total activity, not performance relative to population or number of potential users. The notebook also lists the highest-population district within each state, including North 24 Parganas in West Bengal, Bangalore Urban in Karnataka, Pune in Maharashtra, and Allahabad in Uttar Pradesh, according to the demographic table used.

Uttar Pradesh and device analysis
The Uttar Pradesh quarterly series shows transaction counts increasing from about 12.5 million in Q1 2018 to about 241.9 million in Q2 2021, roughly 19.3 times the initial value. Transaction amount increases from about INR 13.94 billion to INR 482.17 billion, around 34.6 times. The notebook also plots the transaction-category mix for Uttar Pradesh in Q2 2021 and creates a state-by-brand user-ratio table. In the saved cumulative state-and-brand ranking, Xiaomi appears as the leading brand across the displayed states. Because the brand data are quarterly snapshots, summing counts across quarters should not be described as a count of unique people.

Data quality and interpretation
The notebook identifies one missing Amount (INR) value in the state table, 28 missing district codes, and four missing district-level Average Transaction Value values. The district-to-state comparison returns two small amount differences of approximately INR 0.01; transaction counts and registered-user totals match for those rows. The notebook's correlation between district population and quarterly transaction count is about 0.359, a modest positive association. It is not a correlation with population density, and population is repeated across quarter-level rows. The result should therefore be treated as exploratory rather than causal or as a per-capita measure.

Limitations and next steps
The project is a descriptive analysis, not a causal study or forecast. Some saved outputs contain zero app opens, and demographic fields include zero values for population or area; those cases should be validated before drawing conclusions. The current notebook also has logic issues to correct: one .count() call counts rows rather than the number of transactions, the transaction-type pivot counts records instead of summing transaction volume, a population-density chart plots Population rather than Density, and the state Average Transaction Value comparison averages category-level values without weighting. A stronger next version would resolve missingness, validate zeros and duplicates, calculate transaction-weighted average ticket size, normalize state and district volumes by population or registered users, and add clear definitions to each chart.

Business application and deliverables
The output is most useful as a baseline performance review rather than a forecasting model. State rankings can help prioritize where to investigate scale, district demographics offer context, device-brand summaries inform compatibility testing, and transaction-category analysis can show where engagement is concentrated. However, a fair decision should combine these views with market-size denominators, user activity rates, and data completeness. The notebook's district-code mapping is an operational aid for consistent joins, while the reconciliation check is a safeguard against silently mixing incompatible tables. A next release should package the cleaned tables, metric definitions, charts, and validation checks into a repeatable workflow so that updated quarters can be added without manually rewriting the analysis. This would make comparisons more reliable and easier for a business stakeholder to audit. The key outcome is a defensible summary of growth plus a transparent record of limitations.

SHORT RESUME VERSION
Analyzed PhonePe Pulse data (Q1 2018-Q2 2021) using Python, pandas, NumPy, Matplotlib, and Seaborn to examine quarterly transaction growth, state rankings, transaction categories, device-brand distribution, and district demographics. Reconciled district and state totals, surfaced missing data and metric-definition issues, and identified a 29.3x increase in recorded transaction count and 43.5x increase in transaction amount across the period.
